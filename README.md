# Not Defteri — Sesli Not Asistanı

"Konuş, unut; gerisini uygulama düzenler." Android için internetsiz ve Türkçe çalışan, sesle kullanılan kişisel not ve görev asistanı. Her şey telefonda kalır.

Durum: **0.1, proje iskeleti** (kayıt çalışıyor; yazıya çevirme, ayrıştırma ve hatırlatmalar sonraki adımlarda). Ayrıntılar: [`docs/PLAN.md`](docs/PLAN.md), [`docs/DURUM.md`](docs/DURUM.md).

## Kaynak
- `web/index.html` — arayüz (WebView içinde çalışır)
- `android/` — Java kaynakları, Gradle'sız derleme betiği (`build_apk.py`) ve `fetch_vendor.sh`
- `CLAUDE.md` — geliştirme rehberi
